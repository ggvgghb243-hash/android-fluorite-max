# Fluorite Max - Android Emulator Overlay UI

Cyberpunk floating menu overlay for Android Emulators (LDPlayer, BlueStacks, Nox, MuMu) and rooted/non-rooted Android devices.

## Features
- **Background Execution**: Runs as a persistent Foreground Service over any game (e.g. Free Fire).
- **Keyboard Hotkey**:
  - `PageUp` (PgUp) -> Toggle Show / Hide Menu
  - `PageDown` (PgDn) -> Toggle Show / Hide Menu
- **Floating Badge**: Tap or click to open/close menu, drag anywhere on screen.
- **Full UI**:
  - 🎯 **Aimbot**: Silent Aim, Scope Aim, FOV Slider, Smooth Slider, Target Bone Dropdown, Hit Chance Slider, Trigger Bot.
  - 👁️ **Visuals**: ESP Box, ESP Line, ESP Skeleton, ESP Health Bar, ESP Distance, ESP Name, Color Selector, Style Selector.
  - 📦 **Misc**: Speed Boost Slider, No Recoil, Fast Reload, Instant Bullet Hit, Night Sky Mode.
  - ⚙️ **Settings**: Header Dragging, Emulator Keyboard Hotkey Info, Save/Reset Config.
